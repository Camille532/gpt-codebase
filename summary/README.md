## 最重要的判断

- 本站点的原始、未施加时差偏移的FES与实测水位变化高度一致：Pearson r=0.9846，去均值差异RMSE=0.1665m。
- 原流程按水边线选择的−0.75h偏移，反而使这两个指标变为0.9408和0.3168m。水边线相关最高的偏移不能直接当成FES模型潮时误差。
- 既有校正后FES与实测两套完整结果的核心结论一致：向海林缘水敏感光谱响应明确，MNDWI去水体制图对潮位敏感，NDVI相对林缘响应较弱。
- 可以把FES作为缺少实测站时的全球潮位背景输入，但本次单站点、99个卫星过境日期不能证明全球绝对水位精度。绝对淹没阈值、狭窄河口和近阈值日期须另做检查。

**务必区分：原始FES潮位直接比较得到的新指标，不代表已经用原始FES重跑了全部生物量、合成和RF流程。两套完整结果中的FES仍是−0.75h校正版本。**
