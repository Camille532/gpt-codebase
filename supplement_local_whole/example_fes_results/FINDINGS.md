# 用本次FES数据已经得到的补充结果

这些结果来自本次上传cangio.zip，沿用其中已有的FES潮位与高低潮合成，不是重新跑出的0小时FES全流程。原主光谱模型105天、严格模型48天；逐日面积原质控72天，174组月份相近的前后期日期配对。

## 1. 原过渡带不能直接当向海过渡带

原300个过渡带样点中，69个满足d_tidal < d_nontidal。其余231个并非在这个几何规则下更靠潮汐区。它们全都仍保留在拆分后的模型中。

## 2. MNDWI提供一个值得继续验证的局部模式

所有数值为相对核心区的额外斜率，单位指数值/m。下表是新补充的双向聚类t区间，不是旧WCR区间。

| 区域/比较 | 主模型估计 | 95%聚类t区间 |
|---|---:|---:|
| 原分区：向海林缘−核心 | +0.028805 | +0.020165至+0.037445 |
| 原分区：全部过渡带−核心 | +0.002506 | −0.000851至+0.005863 |
| 拆分后：向海林缘−核心 | +0.028807 | +0.020167至+0.037448 |
| 拆分后：靠潮汐区过渡带−核心 | +0.009766 | +0.002350至+0.017182 |
| 拆分后：其余过渡带−核心 | +0.000440 | −0.002868至+0.003748 |
| 拆分后：向海林缘−靠潮汐区过渡带 | +0.019042 | +0.009545至+0.028538 |

靠潮汐区过渡带主模型MNDWI的6指标内FDR q≈0.031；48天严格模型仍同向（+0.008827/m），但FDR q≈0.123，证据减弱。不要把它写成已经确立的普遍林内递减规律，也不能叫已划定的淹没梯度。它支持进一步调查这个方向。

## 3. 规则法面积变化确有较强的林缘贡献

本段使用原空间分区。NDVI＋MNDWI规则法，高潮合成减低潮合成：

| 区域 | 识别面积差ha | 相对该区域低潮结果 | 对全林变化的贡献（全林低潮面积作分母） |
|---|---:|---:|---:|
| 向海林缘 | −290.21 | −9.11% | −0.657个百分点 |
| 全部过渡带 | −14.27 | −0.20% | −0.032个百分点 |
| 两者合计 | −304.48 | −2.99% | −0.689个百分点 |
| 其余森林 | −193.03 | −0.57% | −0.437个百分点 |
| 全林 | −497.51 | −1.13% | −1.126个百分点 |

向海林缘占固定参考森林面积约7.27%，其面积差占该方法全林净面积差约58.33%。本例各原分区面积差同向，整体差异较小不能解释为不同分区增减相互抵消；分母扩大也是原因之一。

这是同一流程高低潮合成的识别面积差，不是已验证的实际森林损失或精度误差。

## 4. 碳量的局部敏感与全林贡献不能混为一谈

同一规则法范围×RF生物量得到的对应地上碳量：

- 向海林缘：−8.49%，绝对差约−11,570 Mg C。
- 原过渡带：−1.27%，绝对差约−4,104 Mg C。
- 核心区：−1.90%，绝对差约−25,125 Mg C。
- 全林：−2.32%，绝对差约−48,602 Mg C。

因此，向海林缘自身的相对变化较大，但核心区范围大，对全林碳量绝对差的贡献仍可能更大。不能把“面积差集中在林缘”直接推广为“所有生物量/碳量差都由林缘主导”。这些总量来自产品参考下的预测，不是实测碳损失。

## 5. 逐日面积的补充结果

在原72天质控下，R1每米潮位对应的面积变化（占各自固定参考面积的百分点）：全林−0.739、向海林缘−4.281、原过渡带−0.359。

额外要求向海林缘与过渡带各自有效覆盖≥80%后剩43天：向海林缘仍为负（−3.956，95%HC1区间−6.507至−1.406）；过渡带为−0.124，区间跨0。说明过渡带面积关系对筛选较敏感，不能只报告72天中的显著结果。

逐日面积模型控制年份与月份，使用HC1，不能解释为独立验证的纯潮位效应。
