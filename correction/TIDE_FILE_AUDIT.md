# h383 潮位文件核查

输入：本次上传的 `h383 (1).csv`。无表头五列：年、月、日、UTC小时、潮位毫米值。

来源核实：[UHSLC h383 元数据](https://uhslc.soest.hawaii.edu/opendap/fast/hourly/h383.nc.info) 指明毫米与缺测码-32767；[官方站点表](https://uhslc.soest.hawaii.edu/erddap/tabledap/global_hourly_fast.subset) 将383识别为Vung Tau、station zero。
